# ICT Labs — SQL лаборатория v3

## Какво е новото
- 3 упражнения.
- 22 самостоятелни задания.
- Всяка тема има няколко задачи: SELECT (3), WHERE (3), ORDER BY (3), DISTINCT (2), JOIN (3), GROUP BY (3), агрегатни функции (2) и комплексни заявки (3).
- Всяко задание има собствен SQL редактор и автоматична проверка на резултата.
- Черновата на SQL заявката се записва автоматично за всяка задача в localStorage.
- При смяна на задача или упражнение написаното се запазва и се възстановява при връщане.
- Всеки браузър има независима база и локално запазени чернови.

## Деплой в Netlify
Разархивирай ZIP файла и качи съдържанието на папката чрез Netlify → Add new site → Deploy manually. Не е необходим build command.

## Важно
Това е учебен прототип с примерна база данни. Заданията и данните трябва да бъдат съгласувани с действителните таблици от ICT Labs. Запазването е локално за браузъра/устройството; няма централизирано предаване на решения към преподавателя.
